# Fonts

**ET Book** — Edward Tufte's digitization of Bembo, used throughout his books.
Bundled here so the serif voice renders the same offline on the Raspberry Pi.

- roman.ttf      — body / titles (et-book roman, line figures)
- semibold.ttf   — emphasis (et-book semi-bold)
- bold.ttf       — heavier emphasis (et-book bold)
- italic.ttf     — italic (et-book display italic, old-style figures)
